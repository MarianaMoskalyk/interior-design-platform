# Interior Design Platform

Веборієнтована інформаційна система для 3D-моделювання інтер'єрів.

## Про проєкт

**Interior Design Platform** — вебзастосунок для створення та редагування 3D-моделей приміщень безпосередньо у веббраузері.

Система дозволяє користувачеві створювати приміщення, налаштовувати їх параметри, додавати меблі та інші об'єкти, змінювати матеріали й текстури поверхонь, а також отримувати розрахунок необхідної кількості матеріалів та орієнтовної вартості ремонту.

У системі також передбачається використання штучного інтелекту для надання рекомендацій щодо дизайну інтер'єру.

## Основні можливості

* створення та налаштування приміщень;
* 3D-візуалізація інтер'єру;
* додавання та редагування об'єктів;
* переміщення, масштабування та обертання об'єктів;
* налаштування матеріалів і текстур;
* розрахунок площі поверхонь;
* розрахунок необхідної кількості матеріалів;
* розрахунок орієнтовної вартості ремонту;
* збереження проєктів;
* рекомендації щодо дизайну за допомогою штучного інтелекту;
* керування каталогом об'єктів і матеріалів.
